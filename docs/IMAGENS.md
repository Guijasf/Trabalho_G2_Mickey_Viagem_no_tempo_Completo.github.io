# Sobre as imagens

O projeto mantém como referências as artes existentes no repositório `Guijasf/Trabalho_G2_Mickey_Viagem_no_tempo_Completo.github.io`:

- `journey.png` — página inicial
- `era-151.png` a `era-155.png` — cinco destinos
- `page-05.jpg` até `page-33.jpg` (páginas selecionadas) — livro consultado durante o jogo

O pacote do código utiliza as URLs públicas dos arquivos existentes; a cópia binária deles **não foi incluída no ZIP**. Para recuperar uma cópia dos JPG/PNG, execute `npm run recuperar:imagens` no computador conectado à internet. O script não altera o GitHub.

**Questões 121, 122, 123, 125 e 126:** as figuras identificadas como A, B, C, E e F não estão presentes completamente na imagem de página 29. Necessário encontrar a ilustração original.

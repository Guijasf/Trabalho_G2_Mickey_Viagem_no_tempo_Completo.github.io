# Trabalho G2 - Pense Bem Mickey: Viagem no Tempo

Projeto de Desenvolvimento Mobile (React Native + Expo) inspirado no livro **Pense Bem — Disney: Viagem no Tempo**.

**5 programas • 150 questões • 3 tentativas • 90 pontos máximos por programa**.

Leia [LEIA_PRIMEIRO.md](LEIA_PRIMEIRO.md) para instalar, testar, publicar no Expo Snack e preencher a entrega.

> **Gabarito provisório.** As 150 respostas ainda requerem conferência com o original; 18 foram inferidas e marcadas como hipóteses. O PDF de entrega é um rascunho, não versão final.

O repositório público de referência é `Guijasf/Trabalho_G2_Mickey_Viagem_no_tempo_Completo.github.io`. Imagens usadas no app são carregadas desse repositório. Material acadêmico sem afiliação com Disney ou Tectoy.
